# AmaliaSeatWell 👶🎮 · IR Lab

אפליקציית Android ל-Poco M3 (או כל טלפון עם משדר IR) ששולטת בנדנדה החשמלית Baby Michel – דגם גלים (BYO59) בלי השלט המקורי.

## התקנה
1. בדף [Releases](../../releases/latest) מורידים בטלפון את `AmaliaSeatWell.apk`.
2. פותחים את הקובץ. אם מופיעה בקשה, מאשרים "התקנה ממקורות לא ידועים".
3. מאשרים הרשאת מיקרופון (משמשת רק לזיהוי הצפצוף של הנדנדה בזמן הסריקה).

כל `push` ל-`main` בונה גרסה חדשה. כל הגרסאות חתומות באותו מפתח, אז מתקינים אחת מעל השנייה בלי לאבד את הקודים שנשמרו.

## איך זה עובד (גרסה 2: IR Lab)
**🏠 מסך הבית:** רשימת שלטים, כשכל שלט מייצג מכשיר אחד. אפשר ליצור שלט חדש, לייבא שלט, לשנות שם, להוסיף שלט למסך הבית כאייקון נפרד, ולייצא אותו.

**🔍 סריקה (לכל שלט בנפרד):**
1. **כיול צפצוף:** האפליקציה מקליטה כמה שניות של שקט, ואז אתם לוחצים 3 פעמים על כפתור במכשיר עצמו. היא לומדת את התדר של הצפצוף ומקשיבה רק לו.
2. **חיפוש:** קודם קודי NEC נפוצים, אחר כך כל הקודים, עד שהמכשיר מגיב. אחרי שמתגלה הכתובת, האפליקציה בודקת את כל 256 הפקודות שלה.
3. **אימות עם ביקורת:** כל קוד חשוד נשלח 3 פעמים, ובין השליחות יש חלונות שבהם לא נשלח כלום. קוד נחשב אמיתי רק אם המכשיר הגיב כשנשלח ולא הגיב כשלא נשלח.
4. אפשרויות: המשך מאיפה שעצרתי, סריקה חוזרת ששומרת את הכפתורים, התחלה מאפס, או הזנה של כתובת ידועה.

**🎮 שלט:** רשת כפתורים שאפשר לעצב: אייקון, צבע, כפתור רחב, סדר והסתרה.
- **🧪 בדיקה מודרכת:** האפליקציה שולחת כל כפתור ושואלת מה קרה. אפשר לתת שם, לסמן "לא קרה כלום", או לאחד אותו עם כפתור זהה.
- **🤖 בדיקה אוטומטית:** בודקת את כל הכפתורים ומסמנת ⚠️ את אלה שלא הגיבו. אחר כך 🧹 מוחק אותם.
- **📤 ייצוא:** כרשימה קריאה, או כקובץ JSON שאפשר לייבא בטלפון אחר.

**⏰ תוכניות:** `שלח נדנדה/הדלקה`, `חכה 20 דקות`, `חזור 3 … סוף`. אפשר להפעיל מיד, בעוד כמה דקות, או בשעה קבועה (גם כל יום).

## טיפים
- משדר ה-IR נמצא בקצה העליון של הטלפון, וצריך לכוון אותו לנדנדה.
- הטלפון צריך להישאר על מטען, והאפליקציה פתוחה (המסך נשאר דולק).
- אם הנדנדה לא מצפצפת, אפשר להפעיל "זיהוי לפי תנועה" או ללחוץ "הגיבה!" ידנית.

⚠️ השליטה מרחוק נועדה לנוחות. יצרני נדנדות מזהירים לא להשאיר תינוק בלי השגחה ולא לתת לו לישון בנדנדה.

## מבנה
- `Ir.kt`: קידוד NEC ושידור דרך `ConsumerIrManager`
- `ReactionDetector.kt`: זיהוי תגובה מהמיקרופון או מחיישן התאוצה
- `Scanner.kt`: הסריקה החכמה
- `ProgramRunner.kt`: מפענח ומריץ תוכניות ותזמונים
- `MainActivity.kt`: הממשק (שלוש לשוניות)
