# AmaliaSeatWell 👶🎮

אפליקציית Android ל-Poco M3 (או כל טלפון עם משדר IR) ששולטת בנדנדה החשמלית Baby Michel – דגם גלים (BYO59) בלי השלט המקורי.

## התקנה
1. בדף [Releases](../../releases/latest) מורידים בטלפון את `AmaliaSeatWell.apk`.
2. פותחים את הקובץ. אם מופיעה בקשה, מאשרים "התקנה ממקורות לא ידועים".
3. מאשרים הרשאת מיקרופון (משמשת רק לזיהוי הצפצוף של הנדנדה בזמן הסריקה).

כל `push` ל-`main` בונה גרסה חדשה. כל הגרסאות חתומות באותו מפתח, אז מתקינים אחת מעל השנייה בלי לאבד את הקודים שנשמרו.

## איך זה עובד
**🔍 סריקה:** האפליקציה משדרת קודי NEC אחד אחרי השני (קודם הנפוצים ביותר בשלטים סיניים, אחר כך את כל 65,536 האפשרויות) ומקשיבה לתגובה: צפצוף, צליל מנוע או שינוי בתנועה. כשהיא מזהה תגובה, היא בודקת לאט את הקודים האחרונים ומאמתת פעמיים. אחרי שנמצא קוד אחד, הכתובת של הנדנדה ידועה, וכל שאר הכפתורים נמצאים תוך כ-3 דקות. ההתקדמות נשמרת, אז אפשר לעצור ולהמשיך מאותה נקודה.

**🎮 שלט:** כל הכפתורים שנמצאו. נותנים להם שמות (הדלקה, מהירות+ וכו').

**⏰ תוכניות:** סקריפטים פשוטים עם הפעלה מיידית, הפעלה בעוד X דקות או בשעה קבועה (גם כל יום):
```
שלח הדלקה
חכה 3
חזור 3
  שלח מהירות+
  חכה 5 דקות
סוף
שלח הדלקה
```

## טיפים
- משדר ה-IR נמצא בקצה העליון של הטלפון, וצריך לכוון אותו לנדנדה.
- הטלפון צריך להישאר על מטען, והאפליקציה פתוחה (המסך נשאר דולק).
- אם הנדנדה לא מצפצפת, אפשר להפעיל "זיהוי לפי תנועה" או ללחוץ "הגיבה!" ידנית.

⚠️ השליטה מרחוק נועדה לנוחות. יצרני נדנדות מזהירים לא להשאיר תינוק בלי השגחה ולא לתת לו לישון בנדנדה.

## מבנה
- `Ir.kt`: קידוד NEC ושידור דרך `ConsumerIrManager`
- `ReactionDetector.kt`: זיהוי תגובה מהמיקרופון או מחיישן התאוצה
- `Scanner.kt`: הסריקה החכמה
- `ProgramRunner.kt`: מפענח ומריץ תוכניות ותזמונים
- `MainActivity.kt`: הממשק (שלוש לשוניות)
